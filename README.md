# LearnHub – A MERN Stack Learning Management System

LearnHub is a full-stack educational platform built using the MERN stack. It enables users to access learning resources, interact with educational content, and experience a seamless digital learning environment.

## Features
- User Authentication
- Course Management
- Real-time Communication
- Responsive Design
- MongoDB Atlas Integration
- Secure API Development

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js
- Socket.io
